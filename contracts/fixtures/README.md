# Contract fixtures

Synthetic example payloads for the contracts in `../README.md`. Every value is fictional: the
people are `alex` and `sam`, devices are named `demo-*`, times are in October 2026.

Both sides test against these files: the engine checks it accepts them, the app or a plugin checks
it produces payloads of the same shape. A new contract adds its fixture here in the same change.
